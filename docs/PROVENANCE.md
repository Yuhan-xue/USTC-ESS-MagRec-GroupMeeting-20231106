# 来源、修订与限制

## 模拟与参考资料

- 算例：`ear-Reynolds-S`；原始服务地址与接口保留在 `download.py`，通过 `pyfefi2` 获取。原始模拟由其提供方维护；本仓库不镜像该数据，也不授予原始模拟的再分发权。
- 分析使用赤道面 `z=0` 与正午—子夜子午面 `y=0`。原生采样与插值网格不同；插值到 0.1 个地球半径并不提高物理分辨率。
- 经典文献、教材名称和引用见报告末尾。教材对照拼图 F37–F45 含第三方页面截图，因此仅保留分析与出处，不随 Git 再分发这些图。
- PPT 含第三方图片及模板元素，完整成品仍在既有网页；仓库不复制模板、论文 PDF、教材 PDF 或 PPT。

## 从工作目录整理出的改动

源代码快照哈希见 `source_snapshot.json`。复制后只作直接相关的可移植性与说明修订：

- `magviz.py` 增加 `MAG_RAW_DIR`，允许从仓库外读取私有原始切面，并在输入缺失时给出明确提示。
- `download.py` 同样支持 `MAG_RAW_DIR`；仅运行下载器才会下载，不在整理、测试、安装或绘制摘要时触发下载。
- `make_movies.py` 改为从 `FFMPEG` 环境变量或系统 PATH 查找 FFmpeg，不保留某台电脑的安装路径。
- `recon_redo.py` 标明旧率代理和未核实电场尺度检查的探索性质；这类结果不在公开的小数据摘要中。
- 仓库报告与讲稿去掉不可用的本地成品链接；讲稿补正 F10 灰带（40°–85° 位置角段，不是准平行区）和 PPT14 左图三种线型。
- 保留原作者分析算法及历史图，不将目录整理包装为新的物理验证。报告中对历史阈值、候选机制与代理量的限制仍适用。

## 复现层级

1. **无需原始数据**：核对缩减时间序列、90 行候选计数、象限均值与摘要图。
2. **需要私有原始切面**：重新计算物理单位、时空图、局地快照、条件平均和诊断。
3. **不随本仓库复现**：用户手工删改后的 PowerPoint 排版、第三方教材截图拼图、原 HTML 托管站部署。未提交依赖本机 Office、个人附件或历史备份的组装脚本，避免提供无法独立使用的伪入口。
