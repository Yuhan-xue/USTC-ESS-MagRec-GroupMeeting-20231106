# 随库小数据

这里只收录统计摘要与缩减的一维量。**不包含原始切面、原始网格、逐帧二维场、二维平均图或 pickle。**

| 文件 | 来源与含义 |
|---|---|
| `eq_timeseries.npz` | `analysis.py` 从赤道面提取的 379 个时刻：日下点和侧翼边界、上游小区域平均参数；每个键是一维数组 |
| `mer_timeseries.npz` | `analysis.py` 从子午面提取的 190 个时刻：旧固定中面 X 线候选、尾瓣场；**不代替新的电流片对齐诊断** |
| `figure_diagnostics_profiles.npz` | `figure_diagnostics.py` 的 671 点一维空间剖面；`Pi_xx_ion_magnetic` 是离子法向应力加磁应力，`scalar` 是标量代理 |
| `diagnostics.json` | 上游参数、边界及历史尾部/雷诺应力的缩减统计；X 线旧口径仍按旧口径理解 |
| `figure_diagnostics.json` | 逐图边界、门槛和局地诊断检查结果；不是二维场 |
| `probes.json` | 侧翼探针和候选周期的少量统计；不含完整探针场缓存 |
| `reconnection_candidates.csv` | 电流片对齐后的 90 个候选时刻，每时刻只保留位置、喷流、象限均值、电场和分类 |
| `reconnection_summary.json` | 从同一批候选导出的分类数、象限均值、位置和电场摘要；有意省略旧率代理与未核实电场尺度检查 |

## 单位

- `t`：模拟代码时间；`tsec`：脚本采用的缩放秒，不能脱离模型尺度直接当真实事件持续时间。
- `mp`、`bs`、`flank_mp`、`flank_bs`、`xline`、`x0`、`z0`、`x`：地球半径。
- `N`：cm⁻³；`Vx`、`vjet_e`、`vjet_t`：km/s；磁场与 `EN/ES/TN/TS`：nT；`T`：eV；压力/应力：nPa；`Ey`：mV/m。
- NPZ 中 `up_` 前缀表示上游小区域平均，`lobe_B` 表示旧尾瓣取样。
- 缺失边界允许为 NaN，不通过填零伪装成边界位置。

## CSV 的口径

`t,x0,z0,nX,vjet_e,vjet_t,EN,ES,TN,TS,full,Ey,cls`

- 先找最接近中面的 `Bx=0` 电流片中心，再沿片找 `-40 < x < -12` 内最靠地球的 `Bz` 负到正反转。
- `cls=clean`：向地喷流 >300、向尾喷流 <−300 km/s，且候选数 ≤2。筛选不使用 `By`；`inactive` 表示至少一侧喷流未过门槛，**不表示已经证明没有重联**；`other` 表示双向喷流过门槛但候选数 ≥3。
- 象限窗口：`0.5 < |x-x0| < 3`、`0.2 < |z-z0| < 1.5`。去除同一个局地窗口的 `By` 中位背景，不逐象限调背景。
- `EN`：向地/北，预期正；`ES`：向地/南，预期负；`TN`：向尾/北，预期负；`TS`：向尾/南，预期正。
- `full=True` 仅表示上述四个均值同时具有预期符号，不是显著性检验，也不是独立识别电子扩散区。
- `Ey` 是 `|x-x0|<0.5`、`|z-z0|<0.3` 的局地窗口平均。

90 帧中筛选后 28 帧，其中 21 帧符号相符；全部候选中 27 帧相符。时刻存在相关性，不能把它们解释为 90 个独立事件。更严格幅值门槛和物理限制见报告。
